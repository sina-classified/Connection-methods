# Security Policy

## Supported Versions

This repository is maintained on a best-effort basis.

| Version     | Supported |
| ----------- | --------- |
| Main branch | Yes       |

---

## Reporting a Vulnerability

If you discover:

* malicious code
* exposed credentials
* insecure scripts
* dangerous configurations
* accidental secrets
* harmful pull requests

please report them privately instead of opening a public issue.

Do NOT publish:

* server IPs
* credentials
* API keys
* active bypass infrastructure
* personal information

---

## Scope

This repository contains:

* educational material
* research documentation
* network protocol analysis
* censorship circumvention information
* testing tools and references

This repository is NOT intended to:

* host malware
* distribute stolen credentials
* provide unauthorized access
* facilitate illegal intrusion

---

## Operational Security

Users are responsible for:

* reviewing scripts before execution
* understanding local laws and regulations
* protecting their own infrastructure
* safely configuring servers and clients

No warranty is provided for:

* uptime
* security
* anonymity
* censorship resistance effectiveness

---

## Third-Party Software

Many referenced tools are maintained by third parties.

Always verify:

* official repositories
* release signatures
* checksums
* binaries

before installation or deployment.

---

## Responsible Research

Contributions related to:

* censorship measurement
* DPI analysis
* protocol research
* networking experiments

are welcome if shared responsibly and legally.
